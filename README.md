# پورتفولیو فرحناز اصغرپور

سایت ایستا (بدون build). همهٔ فایل‌ها را روی هر هاستی (Netlify، Vercel، GitHub Pages، cPanel) آپلود کنید.

## قبل از انتشار حتماً انجام دهید
1. `https://example.com` را با دامنهٔ واقعی عوض کنید (`index.html`، `robots.txt`، `sitemap.xml`).
2. لینک GitHub و LinkedIn را اضافه کنید (برای کارآموزی مهم‌ترین موارد‌اند).
3. برای پروژهٔ رادمهر گروپ اسکرین‌شات واقعی و لینک دمو یا ریپو بگذارید.
4. (اختیاری) یک عکس پرتره رسمی اضافه کنید؛ فعلاً عکس شخصی حذف شده است.

## امنیت
- CSP سخت‌گیرانه بدون اسکریپت/استایل inline (`<meta>` و `_headers`). هدرهای `_headers` فقط روی Netlify/Cloudflare Pages خودکار اعمال می‌شوند؛ روی هاست‌های دیگر در تنظیمات سرور اضافه کنید.
- GSAP (هسته) و Lenis از jsDelivr با نسخهٔ ثابت لود می‌شوند. برای امنیت و سرعت بیشتر فایل‌ها را در `assets/vendor/` محلی کنید و `https://cdn.jsdelivr.net` را از CSP بردارید.

## ساختار
`index.html` · `css/style.css` · `js/main.js` (ترجمه، تم، منو، GSAP، Lenis) · `js/theme-init.js` (جلوگیری از پرش تم)
